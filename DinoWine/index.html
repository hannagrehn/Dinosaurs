DinoWine

A dino balancing a wine glass, Chrome-dino style.

This one's a native desktop game written in Java (Swing), so it doesn't run inside the browser like the other games — but it's just as quick to launch from a terminal.

Run it

From the repo root, compile and run the Java file:

javac DinoWine.java
java DinoWine

Requires a JDK (Java 8+) installed and available on your PATH. A window will open with the game running.

How to play

  • ← / → — shift your weight to keep the wine glass balanced.
  • SPACE — jump over cacti, and also starts or restarts the game.
  • Don't let the glass tip too far in either direction, and watch out for sudden wind gusts!
  • Three lives per run. Your best score is saved locally to highscore.txt.
